为什么切后台是"降频续拉"而不是"停止拉片" · 页面没被冻结时继续拉片,续约窗口才不会过期; 一旦被系统冻结,已缓冲的 15~30s 顶住这段时间 —— 服务端因 45s 窗口仍保持采集,回来即无缝续听。 若"拉满就不管了",续约到期服务端会停采,缓冲耗尽后声音彻底停住。

安卓建议"添加到主屏幕"

标签页在内存紧张时可能被系统回收;主屏幕方式打开时后台表现更稳。

不做的事

不常驻、不自启、不做录音存档;"页面被系统回收 / 浏览器被完全关闭 / 手机重启"后不会继续播放。

延迟口径

200~500ms 属正常(受片长与播放器缓冲下限约束);几十毫秒在本方案不可达,不承诺。
