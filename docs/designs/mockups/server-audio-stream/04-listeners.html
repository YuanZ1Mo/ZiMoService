收听信息与监听者

一份数据两种呈现:普通用户只看到人数,开发者/管理员额外看到账号与地址明细 —— 由服务端"字段是否存在"决定,前端不做权限判断
每 5 秒轮询 · 未播放时不轮询
普通用户(仅人数)
level ≤ 1
当前 2 个会话在收听 明细仅开发者与管理员可见
listeners 字段整体不下发(不是空数组)—— 前端按字段是否存在决定渲染,不写死"没人听"。
未在收听(空闲态)
无人续约时采集线程自行停止并释放音频设备 —— 界面用"未在收听"如实表达,不用 0 伪装在线。

列表口径 = 续约窗口未过期

与"按需采集的离场判定"同一口径:窗口过期即移出,不做"最近听过的人"这类模糊集合。

本接口不计入活跃度

它只做观察,不延长任何人的续约窗口 —— 否则"开着页面不播放"会让采集永不停止。

不下发任何凭据

只给账号、角色等级、IP 与时间;不含会话、令牌、密码类字段。轮询失败按普通网络错误静默重试,不打断播放。
