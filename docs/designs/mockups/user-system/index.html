⑤ 动效规范(低 CPU 硬约束)

只动 transform / opacity;时长短、低频次;支持 prefers-reduced-motion 自动降级为静态

微交互hover 提升 translateY(-1~2px) 150-200ms ease-out · 按压 scale(.97)
按钮/卡片/导航项统一;不改变布局尺寸,仅位移与阴影过渡
状态脉冲心跳在线点 · pulse 2s infinite(仅 opacity/scale)
唯一常驻动画,元素尺寸 7px,开销可忽略;404 漂浮体 4-8s 慢速
进出场fadeUp 400ms · 列表 stagger 每项延迟 60-80ms · 模态/抽屉 300ms
路由切换淡入;抽屉 translateX 滑入;退场比进场快(200ms)
骨架屏shimmer 1.4s · 渐变扫过(translateX)
仅列表/卡片加载时出现;暗色主题降低扫光亮度
降级与禁止项 @media (prefers-reduced-motion: reduce) → 全部动画时长压至 0.01ms
禁止:常驻高频动画、实时 Canvas 粒子(除用户主页特效区显式触发)、触发布局/重绘的属性动画(width/top/left)

⑦ 全局设计原则

信息层级卡片化
卡片承载一切内容区块:白卡 + 蓝调阴影浮于冷白底;暗色下用亮度层级替代阴影层级
反馈及时分层
字段级(输入框下) → 区块级(banner) → 全局级(Toast);破坏性操作一律模态二次确认
空态有引导
空数据给插画 + 主行动按钮(如"清除筛选");错误态可视化,不只靠颜色(图标 + 文案)
服务端驱动渲染
侧边栏 = 模块清单接口;表格列 = 列元数据接口;改配置不改前端代码
可访问性基线
正文对比度 ≥ 4.5:1 · 焦点环可见 · 触控目标 ≥ 44px · 图标配 aria-label · 装饰图形 aria-hidden
响应式断点
≥1440 宽松 · 768-1440 标准 · ≤768 侧栏转遮罩抽屉、表格横滑、表单弹层转全屏
