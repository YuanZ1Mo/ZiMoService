分享页 · 浏览区向空间靠拢

列表改用与空间文件区同一套组件;补搜索、视图切换、单选/多选、右键菜单、详情。下载动作从信息卡移到工具条与右键菜单
改造要点(先看这一页的四个"搬过来"与两个"新加的")
搬过来:① 列表 = 空间文件区那份 FileList(虚拟滚动、列表/网格、表头全选半选、行尾 ⋯、排序表头);② 选中手势 = 单击单选 / Ctrl 加选 / Shift 连选 / Ctrl+A 全选 / Esc 取消;③ 批量条 = ≥2 项时替换工具条;④ 面包屑 = 空间同款(首级是分享名)。
新加的:⑤ 顶部搜索框(搜当前目录及子目录,结果标红并多一列"位置");⑥ 右键 → 详情;⑦ 顶部品牌条右侧的亮/暗切换。
不改的:页面仍是免登录独立全屏页,顶部品牌条、分享信息卡、提取码/需登录/失效三个状态、底部标识全部保持原样。

①浏览态 · 默认(整页)

信息卡只留"分享身份 + 剩余有效期 / 下载次数 / 暂不可用数",原来钉在卡片右侧的下载按钮移到工具条。 列表卡片内是面包屑 + 与空间页逐列相同的表格(名称 / 类型 / 大小 / 修改时间 / 行尾 ⋯),表头可点排序。

⑨逐条对照

现在改后
列表 ShareView 自己写的表格:列写死、无排序、无虚拟滚动、无网格 直接用空间文件区那份 FileList:虚拟滚动(>300 行)、列表/网格双视图、表头点击排序、长名截断
选中 单击 = 切换一项;没有加选、连选、全选、Esc 单击单选 / Ctrl(Cmd) 加选 / Shift 连选 / Ctrl+A 全选 / Esc 取消;表头复选框三态(全选、半选、清空)
批量 无批量条;选中数只反映在顶部按钮文字上 选中 ≥2 项时工具条换成批量条:已选 N 项 · 总大小 · N 个文件夹 + 取消;操作走右键菜单
行操作 行右侧一个"打开/下载"文字按钮 行右侧⋯按钮(悬停/选中时出现),与右键同一份菜单
左键 双击文件夹 = 进入;双击文件 = 直接下载(无反馈) 双击文件夹继续下钻;双击文件下载(与空间页一致);文件夹名可点进
右键 无菜单(浏览器默认菜单) 条目:打开 / 下载 / 打包下载 / 详情;空白处:返回上一级目录;菜单贴底时自动向上弹
顶部 只有分享信息卡 + 一个下载按钮 信息卡(身份与有效期)+ 工具条(搜索框 / 下载全部 ▾ / 列表-网格 / 刷新);下载动作移出信息卡
搜索 无 搜当前目录及子目录;键入停止 400ms 自动搜、命中标红、多一列"位置"、可一键退出
下载 "下载全部(zip)"与"下载所选(N)"挤在同一个按钮上,靠有没有选中来变字 工具条"下载全部 ▾"(当前目录 / 整个分享);选中项走右键菜单的"下载 / 下载所选(N)"
详情 无 右键 → 详情:单条给字段表(名称/类型/大小/位置/创建时间/修改时间),多选给汇总(条目数 / 文件夹数 / 总大小)
不改 — 品牌条、分享信息卡、提取码 / 需登录 / 已失效 / 暂不可用四个状态、底部标识、免登录访问方式
需要后端配合的两处(前端做不到)
① 分享内搜索:公开面列目录接口目前只认排序与分页,没有关键词。要按空间页那种"搜当前目录及子目录"来搜,得给分享的列目录加一条搜索分支 —— 单条目分享可以直接复用空间那份子树搜索;多条目分享的"虚拟根"要逐个分享根搜完再合并,并且每条把路径里分享根往上那几级裁掉(否则会漏出分享者的上层目录名)。
② 虚拟根排序:多条目分享的顶层现在是"按绑定顺序平铺",点表头排序不会生效。要么在那里补上排序,要么干脆让虚拟根的表头不可排序(与"平面平铺"的语义也更自洽)。
